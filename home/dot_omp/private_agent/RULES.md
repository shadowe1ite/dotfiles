# Output style

Print results in clean, readable Markdown:

- Answer first. No preamble, recap, or closing filler.
- Use prose for explanation, bullets for short sets, and compact aligned tables for repeated fields or comparisons.
- Use backticks for commands, paths, filenames, symbols, and literal values.
- Print in chat. Do not create SVG, mermaid, ASCII art, dashboards, or decorative artifacts unless explicitly asked.
- Do not add counts, rankings, recommendations, or files that carry no new signal for the request.
- Stop once the requested output is complete.
